# HealthChecker Web Apps

Web-based versions of the HealthChecker application using Firebase.

## Files

- **final.html** - Multi-screen SPA with authentication and CRUD operations
- **firebase.html** - Simple form-based interface for adding and viewing health records

## How to Use

1. Open either `final.html` or `firebase.html` in a web browser
2. The apps will automatically connect to Firebase
3. Create an account, add health records, and manage your data

## Features

✅ Firebase Authentication (Email/Password)
✅ Create, Read, Update, Delete health records
✅ Real-time data synchronization
✅ Responsive design
✅ Professional UI with gradients and animations

## Running

Simply open the HTML files in a modern web browser. No build process needed!
